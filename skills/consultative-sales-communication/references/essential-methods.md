# 可执行的沟通精华

按当前阻塞选一项，不把整张表当成话术清单。每条都是沟通判断工具，不能证明采购意向、技术可行性或方法有效率。

接话、自我表达与话题延展的具体判断见 [conversation-foundations.md](conversation-foundations.md)。

## 识别与理解

| 规则 | 触发条件与动作 | 停止线与反例 |
|---|---|---|
| M01 行为证据 | 客户提供资料、时间或同事时，记录实际完成的动作与尚未闭合的环节。 | 热情、长回复、头像或外貌不能替代动作证据。 |
| M02 情境优先 | 同一短答可能有不同原因；只在原因会改变动作时求证。 | 不给沉默、忙或改期配上隐藏动机。 |
| M03 综合确认 | 新信息改变下一句；需要对齐理解时，简短归纳结果、约束和未知，允许纠正，只问决定性缺口。 | 不逐轮复述或只抓有利于推荐产品的一条；没有决定性缺口可以不问，客户纠正后更新判断。 |
| M04 单轮目标 | 将本轮目标写成一个可观察结果；删掉不服务该结果的内容。 | 开场同时介绍、查需求、询预算和约见属于目标堆叠。 |
| M05 有用交换 | 有真实且相关的观察、验证方式、事实或己方动作时再贡献；肯定应落在客户已表达或可核实的具体内容上。 | 分享与肯定不产生回报义务；不编经历、不空泛奉承、不倾倒个人隐私，也不要求每轮必须贡献或提问。 |
| M06 自然表达 | 用客户已理解的词和用户自己的语气，保留重要条件；展开前确认与当前问题的关联，类比仅用于解释。 | 不机械模仿、不用术语遮住风险、不强行制造共同点；类比不能证明性能、适用性或结果。 |

## 推进与边界

| 规则 | 触发条件与动作 | 停止线与反例 |
|---|---|---|
| M07 阶段证据 | 进入方案、报价或采购动作前，检查前置条件是否真实闭合。 | 愿意见面不等于有预算；个人认可不等于组织同意。 |
| M08 最小动作 | 根据当前顾虑给一个成本明确、可拒绝的验证或确认动作。 | 不把“可以看看”写成下单；不通过连续小请求累积压力。 |
| M09 具体同意 | 区分看资料、通话、引荐、采购与公开引用各自的许可。 | 一项同意不延伸为下一项授权，关系好也不例外。 |
| M10 尊重停止 | 客户拒绝某个动作时停止该动作；保留已经同意的服务责任。 | 不换渠道、不用玩笑、不靠假紧迫绕回同一请求。 |
| M11 对齐异议 | 把“贵、不合适、不放心”还原成比较范围、标准或缺失证据。 | 不先反驳或降价；明确拒绝不需要被销售改造成待说服对象。 |
| M12 相关举证 | 对当前顾虑只补最相关的真实证据，说明它能证明和不能证明什么。 | 名气、关系、单一成功案例不能证明本项目必然成功。 |
| M13 诚实边界 | 把可做、待核实、明确不能做分开；给自己的核实动作和更新时间。 | 不把自信、经验或历史报价写成当前能力和结果保证。 |
| M14 真实约束 | 发送时核实期限、库存或资源条件，并说明失效时间和替代选择。 | 倒计时和稀缺必须有当前依据；不能用“可能”包装假消息。 |

## 组织与兑现

| 规则 | 触发条件与动作 | 停止线与反例 |
|---|---|---|
| M15 角色路径 | 识别使用、技术、采购、预算与审批环节；未知角色保持未知。 | 联系人的帮忙不证明权限；不要求其越权或绕过本人。 |
| M16 双方动作 | 仅把双方同意的事项写成动作、责任人、日期和完成证据。 | 讨论、意愿与已完成要分开；不替客户承诺行动。 |
| M17 价值跟进 | 业务跟进依据约定节点、新证据、已完成动作或必要风险更新。 | 不因时间流逝反复催；正常交流不必转业务；营销退出不取消交付更新。 |
| M18 自我调节 | 发送前识别自己是否在缓解焦虑、逞强或讨好，暂停后回到事实。 | 不把情绪调节变成冷落客户、报复或拒绝履约。 |
| M19 共情行动 | 承认明确表达的影响，按当前需要选择倾听、补事实或处理；涉及已承担的服务责任时，仍给可负责的处理或反馈节点。 | 不猜心理、不先辩解、不自动给方案或节点；倾听不能代替履约，反馈节点不等于解决期限。 |
| M20 轻度幽默 | 已有轻松语境且双方舒适时，最多补一句相关观察。 | 笑声不是许可；投诉、风险和违约场景优先准确负责。 |
| M21 一致兑现 | 记录承诺并准时更新，偏差出现后主动说明事实与新的检查点。 | 不能用频繁问候、热情或礼物替代交付证据。 |
| M22 修复误解 | 确认自己哪里理解错、影响什么，修正记录并提出一个修复动作。 | 道歉不抹去义务；客户解释错误不代表采购投入增加。 |

## 对比与训练

| 规则 | 触发条件与动作 | 停止线与反例 |
|---|---|---|
| M23 尊重性对比 | 对齐共同目标后，以可验证差异说明选项的代价和适用条件。 | 不贬低客户或竞品；允许保留选择，不制造人格评价。 |
| M24 案例边界 | 案例说明场景、约束、行动、实测结果和不可外推条件。 | 无权限不披露身份；个案不能被写成因果规律或成功率。 |
| M25 真实反馈 | 用实际回应和后续行动改进下一步；关系变化与业务结果分开记录。 | 不编造客户反应；没有结果保持未知；一次成交不建立普遍法则。 |
| M26 双向退出 | 关键约束无法满足时，说明差距并退出当前方案或提供真实转介。 | 退出不是惩罚；订单、服务和纠错责任仍须完成。 |

## 三项组合使用

- 客户长段说明：M03 综合确认 → M11 找主要顾虑 → M08 给最小动作。
- 有兴趣但组织路径未知：M01 记录事实 → M15 明确角色 → M16 协商双方动作。
- 出现交付问题：M19 接住影响 → M13 区分核实与保证 → M21 兑现更新。
- 报价后无回复：M18 检查自身焦虑 → M17 核对联系依据 → M10 尊重停止范围。

出现任何硬性边界冲突时先执行停止线，不能用别的规则抵消。需要项目事实核验时移交相应流程。
