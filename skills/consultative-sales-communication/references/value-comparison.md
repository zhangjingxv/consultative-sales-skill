# 把价值比较算清楚

价值表达要帮助客户判断“多花的钱是否值得、便宜的方案是否够用”。先统一比较口径，再展示可核对的差异；本页用于销售沟通，不替代配置、兼容性确认或核价。

## 先确认是否在比较同一件事

| 比较维度 | 统一口径 |
|---|---|
| 数量与能力 | 相同台数、业务负载、容量和必要性能条件 |
| 产品与配置 | 型号、组件、版本、许可和必要配件逐项对应 |
| 交付范围 | 运输、安装、迁移、调试、培训是否包含 |
| 服务条件 | 保修期限、服务地点、响应方式与实际责任方 |
| 商务口径 | 币种、含税或未税、付款条件、报价有效期 |
| 时间范围 | 同一使用年限、负载假设及更新周期 |

不能对齐的部分单独列出，说明对选择的影响。不要拿含服务方案和裸硬件价格直接比高低，也不要用更高配置替代客户实际需要。

## 每个输入都留下出处

记录：数值、单位、来源、来源日期、适用范围，以及它是已确认事实、估算还是假设。来源可以是有效报价、客户工单记录、计量数据或经客户确认的成本口径。

没有来源的数值可以用于明确标注的演算，但不能写成客户已实现的收益。旧报价、其他项目数据和厂商实验结果也不能自动套用到本项目。

| 输入 | 必填口径示例 |
|---|---|
| 采购成本 | 元／套；含哪些组件、税费和一次性服务 |
| 运维工时 | 小时／年；哪些任务、统计样本与覆盖期间 |
| 工时成本 | 元／小时；客户确认的成本构成 |
| 能耗 | 千瓦 × 小时／年 × 元／千瓦时；负载与电价来源 |
| 维护与续费 | 元／年；保修、许可和订阅是否重复计入 |
| 退出与残值 | 同一时点的费用或回收金额；依据与不确定性 |

## 公式与边界

```text
年度运维工时成本 = 年度相关工时 × 经确认的每小时成本
期间成本 = 初始采购与实施费用
         + 各年维护、许可、能源及运维成本之和
         + 退出费用 − 同口径残值
方案差额 = 方案 A 的期间成本 − 方案 B 的期间成本
```

同一费用只计一次。若工时成本已包含外包服务费，就不能再次把同一服务费全部加进去。

未纳入或未知项目逐项列出，不能当作零。只有范围完整且口径明确时才称完整 TCO；否则称“已纳入成本小计”。长期比较还应与客户确认是否采用折现及统一折现率。

## 可演算的假设示例

以下全部为 2026-10-24 编写的原创演算假设，不是报价、实测结果或收益承诺。假设两套候选满足相同业务需求，采用三年、不折现、同币种同含税口径比较。

| 输入 | 方案 A | 方案 B | 来源、单位与状态 |
|---|---:|---:|---|
| 初始采购与实施 | 120,000 | 126,000 | 本例假设；元／套；待有效报价替换 |
| 相关运维工时 | 120 | 80 | 本例假设；小时／年；待工单或试点核对 |
| 每小时成本 | 200 | 200 | 本例假设；元／小时；待客户确认 |
| 比较年限 | 3 | 3 | 本例假设；年；待客户确认 |

本例只纳入采购实施和相关运维工时。能源、续费、其他维护、退出费用及残值尚未纳入，不能据此声称完整 TCO 更低。

```text
A 三年已纳入成本 = 120,000 + 3 × 120 × 200 = 192,000 元
B 三年已纳入成本 = 126,000 + 3 ×  80 × 200 = 174,000 元
三年差额 = 192,000 − 174,000 = 18,000 元
假设每年少用工时 = 120 − 80 = 40 小时
工时成本等值 = 40 × 200 = 8,000 元／年
```

这些结果只能说明：在所列假设和成本范围内，B 的三年小计少 18,000 元。若实际只减少 10 小时／年，三年工时成本等值恰好抵消 6,000 元采购差额；少于此值时，该项不足以抵消差额。

## 工时等值不等于现金收益

人员仍在岗、工资不变时，节省工时可能只是腾出处理其他任务的能力，不能直接说每年少付 8,000 元。是否减少外包支出、加班费或其他实际付款，需要客户确认。

不能拿三年累计差额直接除采购投入，宣称若干个月回本。回本判断要基于增量投入、各期可实现的净现金流和发生时间；没有这些输入，就不提供回本期。

也不要自行估算停机一小时损失、销售增长或利润增幅。缺少客户业务数据和归因依据时，只说明待验证的影响，不把它加进收益总额。

## 把计算变成一个采购判断

先说选择依据，再给最少必要数字，最后提出一个待确认动作：

> 两版都按您确认的需求比较。B 的采购价多 6,000 元；如果每年确实能少做 40 小时重复维护，按本例工时口径，三年已纳入成本会少 18,000 元。这是待验证的工时等值，您方便先确认一下目前这类维护一年大约花多少时间吗？

数字确认后再讨论是否值得购买。若客户只需要基础能力，且额外价值不能证实，明确推荐够用的较低成本方案；若差异已验证，就用双方确认的依据提出采购下一步。
