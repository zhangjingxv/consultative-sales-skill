# 谈判与承诺

## 谈判前先闭合范围

确认双方讨论的是同一产品／服务范围、数量、税务、服务、交付、付款、验收和风险口径。范围未闭合时，价格比较只能标为不可比或待确认。

## 让步规则

- 不先于客户明确顾虑主动降价。
- 每次让步都要说明变化了什么条件，不制造无条件折扣。
- 让步必须处于用户或组织的真实授权内。
- 不虚构领导审批、最低价、竞争报价或最后期限。
- 不用沉没成本、羞耻或人情债迫使客户接受。

## 交换而非单向退让

可交换的条件包括范围、数量、服务级别、付款节点、交付批次、承诺期限和双方资源投入。只有条件真实可执行时才提出。

```text
如果把【条件A】调整为【条件B】，我可以再核实【对应让步】；当前还没有审批结果，我确认后再给您明确答复。
```

## 价格异议

1. 确认比较基准。
2. 区分预算不足、价值不清、范围不同和风险溢价。
3. 只处理主要原因。
4. 必要时提供可比较方案，不隐藏差异。

## 确认承诺

会议或谈判结束时记录：

- 已确认事实；
- 未解决问题；
- 每个动作的责任人；
- 明确日期；
- 下一次判断或决策的标准。

客户说“差不多”“原则上”时，不自动转换为订单、预算批准或最终接受。

## 退出

当关键条件无法满足、继续沟通需要虚假承诺、或双方没有可执行交集时，明确说明差距并退出当前方案。诚实退出也是信任资产。
