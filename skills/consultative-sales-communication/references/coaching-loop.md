# 销售判断力训练闭环

## 目标

让用户逐步掌握判断，而不是无限依赖代写。把每次沟通视为一次有记录的预测，不把单次回复或成交当作普遍规律。

## 训练步骤

1. 用户先写客户信号、当前阶段、本轮目标和候选话术。
2. Skill 指出一项最关键判断偏差和一项表达风险。
3. 给最小修改版，不重写成完全不同的个人风格。
4. 用户回填客户实际回应和后续动作。
5. 标记结果为有效、无效或未知，并解释为什么仍无法归因。

## 复盘字段

```text
客户原话：
已确认上下文：
我的预测：
我采取的动作：
客户实际回应：
后续实际动作：
本轮结果：有效／无效／未知
可复用规律：
仅适用于该客户的偏好：
```

## 失败模式分类

- 信号误判：把礼貌、长回复或情绪当成意向。
- 阶段跳跃：需求未闭合就谈方案、折扣或成交。
- 目标过多：一轮同时问多个方向。
- 价值不足：跟进没有新信息或新动作。
- 证据越界：承诺价格、交期、兼容性或权限。
- 压力过高：拒绝后继续推进或制造假紧迫。
- 表达问题：太长、模板味、内部术语、没有回应入口。

## 纳入Skill的条件

只有同一失败模式或有效规律在多个匿名化场景重复出现，并且没有违反事实、伦理和客户利益边界，才写入通用Skill。单个客户的特殊偏好留在客户记录中。

## 评价标准

优先评价：事实准确、阶段匹配、客户是否能清楚回应、下一步是否被双方执行、是否保护长期信任。回复率和成交率只能作为结果指标之一，不能单独证明方法正确。
