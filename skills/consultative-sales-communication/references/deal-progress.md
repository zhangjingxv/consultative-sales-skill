# 从报价走向订单

目标是帮助客户完成合适的采购，并让彼此合作更自然。友好、愿意聊、收过报价，分别是关系或沟通信号；只有实际采购动作才推进订单状态。

## 先画清交易链条

中文 ToB ICT 业务可能经过甲方、集成商、渠道和厂商。不要根据联系人职位或公司名称推定谁有采购权限。

| 必须识别的角色 | 要确认的事实 | 可核对的结果 |
|---|---|---|
| 谁使用 | 实际使用单位、业务场景、上线目标 | 使用范围或需求确认 |
| 谁评审 | 技术、安全、业务分别由谁确认 | 评审意见及未关闭项 |
| 谁下单、谁签约 | 采购发起人、采购主体、买卖双方 | 采购流程、订单或合同主体 |
| 谁付款 | 付款主体、预算来源、约定付款节点 | 付款条件及审批路径 |
| 谁负责服务 | 供货、安装、调试、保修、报修分别由谁承担 | 已确认的交付和服务范围 |

同一公司可能承担多个角色；同一个人也可能只负责其中一步。甲方使用，不等于甲方向我们下单付款；厂商保修，也不等于厂商承担现场安装。

典型链条仅用于排查：甲方确认业务目标，集成商整合交付，渠道向上游采购，厂商提供其合同范围内的产品与支持。实际分工以本项目确认内容为准。

先向现有联系人问清一处缺口，不绕过联系人私自找其客户或上级：

> 为了把这份报价交给对的人，想确认一下：这批设备由贵司下单，还是由最终使用单位采购？

涉及多级转售时，分别记录“我们卖给谁”和“谁最终使用”，不把上游的供货条件直接写成下游已接受的条件。

## 报价后找出当前唯一阻塞

报价发出后，先判断客户现在卡在哪一步：方案不确定、价值不认可、预算不足、采购流程未到，还是暂时没有需求。一次沟通先解决最影响下一步的一项，其余未确认项仍保留。

| 本轮只记录一项 | 写法 |
|---|---|
| 当前阻塞 | 客户认可的具体问题，不替客户猜原因 |
| 关闭条件 | 哪份资料、哪项验证或谁的确认可以解除 |
| 双方动作 | 我方提供什么、客户由谁确认 |
| 时间与证据 | 双方约定的节点，以及何种结果算完成 |
| 关闭后的动作 | 采购申请、合同审核、订单确认等明确一步 |

“再看看”“跟领导说了”没有明确关闭条件。可以温和收口：

> 目前主要是服务范围还没确认，对吗？我把安装和保修分别列清楚；这项确认后，我们下一步就对接采购申请。

如果对方纠正了阻塞判断，就更新判断；不要把自己希望解决的问题当作客户真正卡住的点。

## 条件齐备，就明确提出采购下一步

技术、价格口径、交付范围和采购路径等必要条件已确认后，直接提出一个合适动作，不无限重复“有进展联系我”。

> 这几项已按您确认的口径更新。方便请采购按这版发起申请吗？我来准备申请需要的报价和附件。

> 如果这版合同条款已确认，您看下一步由哪位同事发起订单？我把对应资料一次补齐。

采购动作仍由有权限的人决定。对方未明确答应，就记录为“已提出，待回复”；不要把沉默或“应该可以”记为已下单。

如果关键条件仍不满足，明确剩余问题和可行替代；如果没有采购计划，就自然暂缓，并约定有实际变化时再联系。

## 原创合成场景一：甲方认可技术，采购尚未开始

甲方 IT 负责人确认两台服务器满足既定需求，财务已有预算安排，但采购尚未收到完整资料。销售与联系人关系很好，每周都聊，却始终没有采购动作。

- 角色确认：甲方使用、评审、签约付款；我方供货；安装和保修按已确认范围执行。
- 本轮阻塞：采购申请缺少服务范围附件，技术认可不能替代采购受理。
- 关闭条件：IT 负责人确认附件内容，采购确认资料齐备。
- 采购下一步：“附件已确认，方便今天转采购发起申请吗？需要的资料我这边一起补齐。”

“今天”只在双方已同意该节点时使用。完成证据是申请已受理或明确的下一流程，不是联系人说“我支持你”。

## 原创合成场景二：集成商采购，甲方验收

集成商负责总项目，向我方采购交换机；甲方网络团队评审并验收。厂商提供其约定的保修支持，我方不承担集成商的软件联调。

- 角色确认：甲方使用评审；集成商向我方下单、签约和付款；服务分工写入双方确认的范围。
- 本轮阻塞：集成商担心供货范围里是否包含现场联调，不能只靠口头“都能配合”。
- 关闭条件：双方确认供货清单、数量、商务交付条件和服务边界，客户另行明确联调负责人。
- 采购下一步：“清单、数量、交付条件和联调分工都已确认，方便按这版发采购订单吗？我来准备对应附件。”

甲方验收安排不自动改变集成商对我方的付款条件。任何变动都要由交易双方明确确认。

## 成交后，让关系自然延续

先完成交付和问题处理，再依据使用结果讨论扩容、续保或下一批需求；不能用聊天热度代替交付满意度。

> 这批设备已经验收，后续使用中有问题您随时找我。等您方便时，我再了解一下是否有下一批计划。

转介绍先征得许可：“如果您觉得这次配合还不错，之后有同事需要这类设备，方便时帮我们牵个线就好。”不索取通讯录、不让客户替销售背书，也不把照顾关系当作下单义务。
