# Contributing

Contributions should improve sales judgment, not merely add more scripts or canned phrases.

## Add a behavior

1. Describe the customer signal and confirmed context.
2. State the current conversation stage.
3. Select one primary turn objective.
4. Add a synthetic regression case under `tests/`.
5. Update the smallest relevant reference file.
6. Run the public-tree audit and tests.

## Content rules

- Use synthetic or fully anonymized examples.
- Do not submit private chats, customer identities, commercial secrets, or credentials.
- Do not submit books, course materials, archives, copied passages, or source inventories.
- Do not create unsupported claims about price, stock, compatibility, delivery, discounts, or authority.
- Do not use humiliation, deception, fake urgency, fake scarcity, or pressure after rejection.
- Keep customer-facing drafts short and natural.

## Pull requests

Explain the failure mode the change prevents. A new template without a corresponding decision rule or test may be rejected.
